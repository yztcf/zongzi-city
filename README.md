# 粽趣城市 3D

端午節主題的大富翁瀏覽器桌遊。專案同時保留原始 2D 完整版與新版 3D 版，兩者可分別開啟，不會互相覆蓋。

## 開始遊戲

建議從專案目錄啟動任一靜態網站伺服器，再用最新版 Chrome、Safari 或 Edge 開啟：

- `index.html`：新版 3D 遊戲。
- `game-2d.html`：改寫前的原始 2D 完整版。

兩個版本都不需要安裝套件或建置。

由於 3D 引擎透過 CDN 載入，遊玩時需保持網路連線。

## 第一版 3D 內容

- 可旋轉、縮放與回到全景的 3D 河港棋盤。
- 六款帶有葉脈、綁繩、五官、手腳與表情的程式化粽子棋子。
- 3D 骰子、分區轉盤、細節建築、龍首龍舟、動態水域、樹木與燈籠。
- 程式化葉片、木材、石材、草地與紙張 PBR 材質；環境反射、柔和接觸陰影與暖冷雙向光源。
- 電影式色彩映射與克制的發光後製、水面波紋與日光閃爍、蓮葉點綴，以及更有層次的粽葉、繩結與待機動作。
- 擲骰特寫、棋子跟隨、落地事件鏡頭與全景鏡頭切換。
- 買地建築升起、金幣粒子、經過起點獎勵及勝利彩紙效果。
- 28 格環形棋盤，包含地產、粽運卡、補給站、建築稅、涼亭與轉盤。
- 1–3 位電腦對手，或 2–4 位本機輪流同樂；完成事件後自動換回合。
- 本機多人可在拍賣中依序加價或放棄，由最後領先者得標。
- 買地、升級、收租、破產、經過起點與「總資產 $2,500」勝利判定。
- 城主榜同時呈現現金、地產數與總資產；落地會顯示河港停靠牌，說明該格效果與資產資訊。
- 桌面、觸控與鍵盤操作：`R` 擲骰、`E` 結束回合、`C` 回到全景。

## 角色技能

每位角色都保有被動加成，並能在自己的回合、擲骰前啟動一次主動技能。

| 角色 | 被動加成 | 每局一次主動技能 |
|---|---|---|
| 糖心粽 | 轉盤正面獎勵增加 $50 | 下次骰子 +2 |
| 鹹蛋粽 | 買地與升級減少 $10 | 下次買地再折 $30 |
| 黑米粽 | 每次收租增加 $5 | 下次租金再加 $20 |
| 綠豆粽 | 正面粽運獎勵增加 $30 | 下次正面粽運再加 $80 |
| 芋香粽 | 可免疫一筆負面事件 | 取得一次免疫 |
| 雙拼粽 | 經過起點額外獲得 $50 | 下次經過起點再加 $100 |

## 技術與素材

- 單一 `index.html`，內嵌介面樣式與遊戲邏輯。
- Three.js r182 與 OrbitControls，透過 jsDelivr CDN 載入。
- 所有 3D 模型均以 Three.js 幾何體在程式中建立，未使用外部下載模型。
- 角色選擇畫面沿用本專案既有 PNG 圖像。

第三方授權記錄見 `THIRD_PARTY_LICENSES.md`。
