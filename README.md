# 🎲 粽趣城市 🏙️

端午節主題的大富翁（Monopoly-style）網頁桌遊。單檔 HTML，瀏覽器直接開即玩，2–6 人同機輪流。

## 玩法

1. 用瀏覽器開啟 `index.html`。
2. 選擇 2–6 位「粽子角色」，按「開始遊戲」。
3. 輪流擲骰移動，停在地產可購買、停在別人地產付租金。
4. 觸發粽運卡、材料補給站、建築稅、轉盤等格子事件。
5. 玩家嚴重負債即破產，最後存活者獲勝。

## 角色與技能

| 角色 | 圖示 | 技能 |
|------|------|------|
| 糖心粽 | 🍬 | 【甜轉再來】轉盤可轉兩次擇一 |
| 鹹蛋粽 | 🥚 | 【快速升級】購地（建屋）減 10 金幣 |
| 黑米粽 | ⚫ | 【收租加成】別人停留你的地產多付 5 金幣 |
| 綠豆粽 | 🟢 | 【雙抽幸運】粽運卡抽兩張擇一 |
| 芋香粽 | 🟣 | 【一次免災】免疫一次負面事件 |
| 雙拼粽 | 🎨 | 【交換人生】交換地產（尚未實作） |

## 棋盤

28 格環形棋盤，含 12 處地產（甜/鹹/綜合/頂級四種口味）、7 張粽運卡格、3 處轉盤、起點、材料補給站、涼亭、建築稅等特殊格，中央為轉盤。

## 技術

- 純前端：HTML + 內嵌 CSS + 原生 JavaScript，無框架、無建置流程。
- 所有遊戲資料定義在 `index.html` 的 `boardLayout` / `characterData` / `fortuneCards`。
